# Как внести вклад в VoidRP

Спасибо, что хотите помочь! Этот файл действует для всех репозиториев организации
[VOIDRP-MINECRAFT](https://github.com/VOIDRP-MINECRAFT), у которых нет своего `CONTRIBUTING.md`.

> 🇬🇧 Issues and pull requests in English are welcome too.

## Куда писать

| Что случилось | Куда |
|---|---|
| Баг в коде, мод крашит, API отвечает не то | Issue в нужном репозитории (шаблон «Баг») |
| Идея или новая фича | Issue с шаблоном «Идея» |
| Вопрос по игре, донату, аккаунту, бану | [Discord](https://discord.gg/j2Dvxm8E) или [Telegram](https://t.me/voidRPminecraft), не issue |
| Уязвимость, утечка, обход авторизации | **Только приватно**, см. [SECURITY.md](SECURITY.md) |

Не знаете, какой репозиторий нужен? Карта репозиториев — на
[главной странице организации](https://github.com/VOIDRP-MINECRAFT) и в [docs/](docs/README.md).

## Пулл-реквесты

1. Сделайте форк или ветку от `main`. Одна ветка — одна задача.
2. Соберите проект и прогоните проверки локально — теми же командами, что в CI
   (таблица в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)).
3. Опишите в PR, **что** изменилось и **зачем**; для визуальных правок приложите скриншот или GIF.
4. Дождитесь зелёного CI. Мейнтейнер посмотрит и сольёт (обычно squash).

### Стиль коммитов

Коротко и по делу, в повелительном или описательном виде. Можно по-русски или по-английски.
Префикс области приветствуется:

```
fix: guard GoalSelector against null goal element
docs(profile): refresh org page
Trader: /game-sync/trader/spawn for /vrgs trader here
```

### Чего не делать

- Не коммитьте секреты: `X-Game-Auth-Secret`, `webgui` HMAC-секрет, токены, `.env`, пароли от БД.
  В конфигах в репозитории — только плейсхолдеры.
- Не заливайте собранные jar, `node_modules`, `build/` и прочие артефакты.
- Не ломайте совместимость протоколов между репозиториями молча: если меняется эндпоинт бэкенда,
  канал `webgui:*` или формат play-ticket — напишите в PR, какие ещё репозитории надо обновить.

## Лицензии

Большинство репозиториев — проприетарные: отправляя PR, вы соглашаетесь, что код может использоваться
в проекте VoidRP. [VoidRP UI](https://github.com/VOIDRP-MINECRAFT/voidrp-ui) распространяется по MIT.
